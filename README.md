# CozyCode 🐑

Уютное приложение для Windows: чат с Клодиком (агент Notion) и **Янкой** — своим ИИ-ассистентом, который работает прямо на ПК через LM Studio.

Это резервная копия рабочей папки `NotionAgentWorkspace` (только код и документы).

## Что где
- `CozyCode_обновление/` — само приложение: `cozycode.py` (окно, чат, сервер), `bridge.py` (MCP-мост для Клодика), `programs.py` (Blender, Roblox Studio по MCP), `window.py` (своё окно pywebview), `ui/` (интерфейс, Яночка, тамагочи).
- `CozyCode_обновление/yanka/` — ядро Янки: модели (`providers.py`, `local.py`), маршрутизация (`router.py`), память (`memory.py`), задачи (`tasks.py`), разрешения (`permissions.py`), связь с окном (`app.py`).
- `CozyCode_обновление/tests/` — тесты: `py -3 -m unittest discover -s tests` из папки `CozyCode_обновление`.
- `PROJECT.md`, `PLAN.md`, `Янка_AI_архитектура.md` — память проекта, план и архитектура.
- `files/янка_задание*.txt` — задания Яны.
- `skills/` — скилы для агента, `blender/` — скрипты 3D-сцены, `tmp/` — проверочные скрипты.

## Чего здесь нет (специально)
Фото и видео, рендеры, резервные копии, папки `data/` с настройками, памятью и ключами. Ключи и адрес туннеля в репозиторий не попадают.

## Установка обновления на ПК
Выключить CozyCode → запустить `CozyCode_обновление\обновить.bat` → включить.
