Что делает Клодик

⚙️ Настройки

Никому не показывай этот ключ.

Больше истории - Клодик лучше помнит разговор, но тратит чуть больше лимитов.

Кроме рабочей папки Клодик может работать только в этих папках. Системные папки Windows и сама папка CozyCode защищены всегда. То, что Клодик удаляет здесь, попадает в Корзину.

Новая папка добавляется при создании проекта - кнопка «📁 Обзор…».

⚡ Команды без вопросов

Сюда попадает то, что ты разрешила кнопкой «✅ Всегда … здесь». Удаление, цепочки команд и опасные программы так не разрешаются никогда.

Клодик может работать прямо в программах на ПК - Blender, Roblox Studio и других, у которых есть MCP-сервер. CozyCode сам запускает его и передаёт Клодику инструменты программы. Перед действиями (кроме просмотра) Клодик спрашивает тебя, а «✅ Всегда» запоминает инструмент.

Другая программа
Команда есть в инструкции MCP-сервера программы (раздел для Claude Desktop или Cursor: command + args).

Перед тем как Клодик перезапишет, изменит или удалит файл в рабочей папке, CozyCode сохраняет копию (последние 300).

Пошагово: как заново подключить Клодика, если ты сменила аккаунт Notion, создала нового агента или что-то отвалилось. Делай шаги по порядку. Сам CozyCode переустанавливать не нужно: переписка, проекты и файлы остаются на ПК.

1. Проверь, что CozyCode и туннель работают

  1. CozyCode запущен, внизу слева точка моста зелёная.
  2. Вкладка «Подключение»: туннель ngrok, адрес <твой-адрес>.ngrok-free.dev.
  3. Если ngrok тоже новый (другой аккаунт ngrok): на dashboard.ngrok.com возьми Authtoken (длинный, НЕ тот, что начинается с rd_) и выполни в PowerShell в папке CozyCode: .\ngrok config add-authtoken ТВОЙ_ТОКЕН. Затем в Domains скопируй бесплатный адрес, впиши его сюда и перезапусти CozyCode.

2. Создай агента в новом аккаунте

  1. В Notion слева: Agents → Новый агент (Custom Agent). Имя «Клодик», иконка 🐑.
  2. Открой его Instructions и вставь текст из раздела «Инструкции для агента» в файле AGENTS.md (он лежит в папке NotionAgentWorkspace, открывается Блокнотом).

3. Подключи к агенту твой ПК

  1. Настройки агента → Tools / Инструменты → Добавить → Custom MCP server.
  2. Название: Yana PC. Адрес: кнопка «📋 Копировать адрес» на вкладке «Подключение» (он заканчивается на /mcp).
  3. Авторизация: Bearer / API key. Вставь ключ из «📋 Копировать ключ». Только сам ключ, без слова Bearer, иначе будет ошибка 401.
  4. Когда подключится, открой Yana PC в списке инструментов и включи все инструменты, особенно cozy_get_inbox, cozy_status, cozy_reply. Новые инструменты бывают выключены по умолчанию.

4. Чат с Клодиком

База сигналов

  1. Создай в Notion базу (таблицу) CozyCode · Сигналы. Хватит одной колонки с названием.
  2. В настройках агента дай ему доступ к этой базе (Full access).
  3. В настройках агента → Triggers / Триггеры → Добавить → «Страница добавлена в базу» и выбери эту базу.

5. Ключ интеграции для CozyCode

  1. Открой notion.so/profile/integrations → Новая интеграция → тип «Внутренняя», имя CozyCode, выбери нужное рабочее пространство.
  2. Скопируй секретный ключ (начинается с ntn_).
  3. Открой базу сигналов → ••• справа сверху → Подключения → добавь CozyCode.
  4. Вкладка «Notion» здесь: вставь ключ и ссылку на базу (база → ••• → Копировать ссылку), нажми «🔎 Проверить», потом «Сохранить».

5. Опубликуй и проверь

  1. В настройках агента нажми Опубликовать: фоновые запуски видят только опубликованную версию.
  2. Напиши Клодику в CozyCode «@клодик привет» (мост включится сам), потом в чате с агентом в Notion отправь точку «.».
  3. Точка «.» в чате с агентом. Это значит «проверь CozyCode». В новом чате в первый раз лучше написать: «. = проверь CozyCode, правила в AGENTS.md».

Если что-то не так

  • 401 / «The server didn't accept the token»: ключ вставлен со словом Bearer или не тот. Вставь заново только ключ.
  • «Tool … is not enabled»: у Yana PC включены не все инструменты (шаг 3.4).
  • Клодик молчит после «.»: агент не опубликован или закончились кредиты.
  • Журнал ошибок: CozyCode\data\cozycode.log, его можно прислать Клодику.

🐑 Янка

Модели на ПК (LM Studio)

Провайдеры

Облачные модели платные. Пока лимит $0, Янка в облако не ходит. Ключи шифруются средствами Windows и в окне не показываются.

Лимит, $ в деньв месяц

Янка сама выписывает важное из разговоров (предпочтения, решения, проблемы). Пароли и ключи не запоминает никогда.

Янка разобьёт задачу на шаги, сделает свои, проверит результат и повторит, если не вышло. Шаги про код, файлы, Blender и Roblox уйдут Клодику - когда он сделает, нажми «✅ Готово».

Что Янка делала на ПК и кто разрешил. Чтение - сразу; изменения - с резервной копией (можно вернуть); установка программ - только с твоего «да»; настройки Windows - запрещены.
