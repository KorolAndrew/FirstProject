name: Python-программы для Windows
description: Когда нужно написать скрипт, утилиту или программу на Python для ПК Яны
source: Клодик
---

- Python у Яны: C:\Python315. Запуск: py файл.py или двойной клик по .bat рядом.
- Сначала стандартная библиотека; сторонние пакеты — только если реально нужно, и предупреди (pip install).
- Пути через pathlib, кодировка файлов utf-8, учитывай кириллицу в путях.
- Для окон — tkinter (есть всегда). Для консоли — понятные сообщения по-русски.
- Добавь .bat-запускалку с pause в конце, чтобы окно не закрывалось при ошибке.
